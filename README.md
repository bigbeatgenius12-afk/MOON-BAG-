# Moon Bag 🌙💰

A simulated crypto meme-coin trading game — play money only, no real cryptocurrency.

Launch your own meme coins, trade with MGOAT, set buy triggers, and compete with bot traders like Zubu and Bobo.

**Live website:** https://blujo-inu-promo.replit.app

## What's inside

- `artifacts/moon-bag` — the Moon Bag website (React + Vite)
- `artifacts/moon-bag-mobile` — the Moon Bag mobile app (Expo / React Native)
- `artifacts/api-server` — the trading engine (Express API)
- `lib/` — shared code (database, API spec, generated clients)

## Building the Android app

The mobile app lives in `artifacts/moon-bag-mobile` and is configured for
Expo's cloud build service (EAS). Build with the **production** profile to
produce a Google Play app bundle (`.aab`).

## Disclaimer

Moon Bag is a game. All coins, prices, and trades are simulated. No real money
or cryptocurrency is involved.
